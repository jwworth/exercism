# Exercism

These are my solutions to the code challenges of [Exercism](http://exercism.io).

This repository mirrors my
[Exercism profile](https://exercism.io/profiles/jwworth).

## Installation

```
brew install exercism
git clone https://github.com/jwworth/exercism
cd exercism
```

Each problem has its own test. Read those test files to determine how to run
them

## JavaScript exercises

Run the JS exercises like this.

```
npm run download:js -- <exercise-name> # Download
npm run test:js -- <exercise-name> # Start tests in watch mode
npm run validate # Validate all JS code

npm run commit # Commit
npm run submit -- <track> <exercise-name> # Submit to Github and Exercism
```
